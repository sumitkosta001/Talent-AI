# Shared Modules

Common artifacts, schemas, types, and helpers shared between microservices, client gateways, and utilities.

## Directory Responsibilities

- **`types/`**: Common python data structures and frontend/backend type mappings.
- **`constants/`**: Global enumeration classes, status indicators, and system tags.
- **`utils/`**: Common logger helper interfaces, text sanitization logic, cryptographical utility templates.
- **`schemas/`**: Shared Pydantic data schemas, JSON definitions.
