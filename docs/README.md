# Project Documentation

TalentAI system architecture logs, schema documents, API specifications, and team alignment materials.

## Directory Responsibilities

- **`architecture/`**: System block designs, microservices topology, ML pipelines layout.
- **`database/`**: Relational entity models, PostgreSQL migrations guidelines, storage specs.
- **`api/`**: Swagger/OpenAPI configurations, gateway definitions.
- **`deployment/`**: Cloud infrastructure architecture patterns, load-balancing systems.
- **`diagrams/`**: Vector diagrams (Mermaid / Draw.io blueprints).
- **`screenshots/`**: UI/UX mockups, pipeline demonstration screenshots.
- **`meeting-notes/`**: Weekly status checks, supervisor feedback transcripts.
